# SnipLite

运行「SnipLite.exe」，通过 Ctrl + Shift + A 或系统托盘开始截图。拖动框选；选择「选区」后可移动或拖动角点调整。选择矩形、箭头或画笔后可选择常用颜色与线宽，设置会保留。文字输入按 Enter 确认、Esc 取消。Ctrl + Z 撤销，Enter 或 Ctrl + C 复制，Esc 取消。

点击「固定」创建桌面贴图。拖动图片移动，滚轮缩放，双击关闭，右键复制、保存或切换置顶；长图可用滚动条查看。托盘设置可更改快捷键、开机启动和默认保存位置。

滚动截图暂不提供。请先退出托盘中的旧版本，再更新程序。构建：运行 build.ps1，需要 Windows 自带 .NET Framework 4 编译器。
